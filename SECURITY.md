# Reporting a vulnerability

[Open a private GitHub security report](https://github.com/New1Direction/webmcp-anything/security/advisories/new).
Identify the affected component and version or commit, describe the impact, and include steps to reproduce with test data. Remove credentials and personal data from logs and screenshots.

Use [GitHub Issues](https://github.com/New1Direction/webmcp-anything/issues) for ordinary bugs and feature requests.
