wmcp.sh

Any website becomes tools an agent can use — no MCP server required.

wmcp.sh is a hosted Cloudflare Worker that turns any URL into agent-callable MCP tools, plus a Chrome extension, open-source adapters, and SDKs. On top of that sits an independent A–F trust graph for the whole MCP ecosystem — the part that's hard to copy.

The spine: read (free, drives reach & acquisition) → execute (governed, paid) → trust (the moat: who's safe to connect to).

1 The two halves

① The product — "WebMCP for anything"

Point an agent at wmcp.sh/api/v1/tools?url=… and any site (Shopify, an OpenAPI spec, schema.org, or LLM-extracted) comes back as callable tools. Live execute (add-to-cart, real actions) runs through a governed OAuth-vault proxy with a kill switch, daily cap, and audit log.

② The moat — the MCP trust graph

An independent, free A–F grade for MCP servers (security/OWASP, spec, reliability, tool hygiene, transparency), continuously re-checked for drift & rug-pulls. The grade is never for sale — we monetize the monitoring/audit around it. Independence is the acquisition premium (Cloudflare can't grade the gateway it sells; Anthropic can't grade its own registry).
